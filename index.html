I build machine learning and natural language processing systems that study and support how software developers communicate, reason about code, and handle security. My group's work spans three areas: analyzing multi-party developer conversations and human–AI interactions (pull requests, chats, issue threads, and coding assistants) to understand how meaning, intent, and tension emerge; evaluating and hardening the security of agentic AI systems that repair, generate, and modify code; and mining fine-grained code changes to help developers locate bugs, predict defects, and assess the risk of AI-generated edits.
