Research Projects

Emotions in Software Engineering -- The research aims to deepen our understanding of the social and emotional dimensions of software development, particularly in collaborative and immersive environments. It seeks to automatically detect and analyze developer emotions and their causes in communication and investigate negative behaviors such as toxicity in large-scale developer discussions. The overarching goal is to build systems and datasets that enable healthier, more inclusive, and more emotionally aware software development communities, as well as more responsive and adaptive tools for developers. In doing so, the research envisions a future where software engineering is not only technically efficient but also socially and emotionally sustainable. [ASE 2022, ICSE 2024a, ICSE 2024b]
 
Software Security and Vulnerability Data -- Large language models are rapidly being integrated into software engineering, yet their security awareness and reliability remain limited. Our work aims to evaluate and improve how these models handle vulnerable code and generate fixes. It also seeks to enhance the quality of vulnerability datasets, which are essential for training predictive and repair models. By addressing both the behavior of LLMs and the integrity of underlying data, we aim to make automated tools more trustworthy for developers. Ultimately, this vision is to enable safer use of AI in programming workflows while producing higher-quality security data for research and practice. [TSE 2025, JSS 2025, EMSE 2025]
 
Changeset-Centric Software Analytics This research explores how fine-grained software changesets can be leveraged to support developer tasks and improve software quality. By modeling and mining sequences of changes, the work advances techniques for feature location, bug localization, and just-in-time defect prediction. It also investigates how changeset-based representations can be integrated with modern machine learning approaches, enabling scalable code clone detection, prediction of developer activity, and automated quality assurance. The vision is to create a comprehensive changeset-centric framework that enhances developer productivity and software reliability through data-driven insights and tools. [CSUR 2024, ICSE 2022]
