Research Projects

Conversational Analysis in Software Engineering. Software engineering runs on conversation — among developers and, increasingly, with AI. We analyze pull requests, issue threads, chats, and human–AI coding sessions to detect derailment, extract decisions, and diagnose breakdowns in human–AI interaction.
Recent: ICSE 2026, ICSE 2024a, ICSE 2024b, ASE 2022.
Security of Agentic AI in Software Engineering. AI agents now write, repair, and review code — often insecurely. We characterize when agentic APR systems introduce vulnerabilities, build threat models and red-teaming toolkits, develop agentic exploit engines, and improve the quality of vulnerability datasets.
Recent: TSE 2025, JSS 2025, EMSE 2025.
Changeset-Centric Software Analytics. Fine-grained code changes carry more signal than repository snapshots. We mine changesets for bug localization, just-in-time defect prediction, and risk assessment of AI-generated edits.
Recent: CSUR 2022, ICSE 2022.
