Research Projects

Conversational Analysis in Software Engineering. Software engineering is fundamentally a conversational activity, conducted among humans and, increasingly, with AI assistants. We study how meaning, intent, and tension emerge across pull requests, issue threads, chats, forums, and human–AI coding sessions using linguistic, social, and emotional signals. We build datasets and models that anticipate conversational derailment, extract opinions and decisions from multi-party discussions, diagnose breakdowns in human–AI interaction (e.g., vibe coding difficulties), and surface the communication patterns that shape software quality and community health.
Recent: ICSE 2026, ICSE 2024a, ICSE 2024b, ASE 2022.
Security of Agentic AI in Software Engineering. Agentic AI systems are increasingly writing, repairing, and reviewing code, but their security behavior and the data they rely on remain unreliable. We empirically characterize when and why agentic automated program repair (APR) systems introduce vulnerabilities, build APR-specific threat models and red-teaming toolkits, develop agentic exploit engines that validate whether reported vulnerabilities are practically exploitable, and create techniques to clean, filter, and quantify uncertainty in software vulnerability datasets. The goal is safer AI-assisted programming workflows and higher-quality security data for research and practice.
Recent: TSE 2025, JSS 2025, EMSE 2025.
Changeset-Centric Software Analytics. Fine-grained code changes carry more information than snapshots of a repository. We model and mine sequences of changesets to improve bug localization, feature location, and just-in-time defect prediction, and we extend changeset-centric methods to assess the risk of AI-generated and mixed-authorship changes, scale up code clone detection, and recognize developer activity. The long-term vision is a changeset-centric framework for developer productivity and software reliability in human- and AI-authored codebases.
Recent: CSUR 2022, ICSE 2022.
